# 💣 Omni Bomb Plugin

Шуточный плагин который "взорвёт" весь Omni!

## ⚠️ ВНИМАНИЕ!

Это **безопасный шуточный** плагин. Он не наносит никакого вреда системе, только показывает уведомления с обратным отсчётом.

## Что делает?

1. **Запускает обратный отсчёт** на 10 секунд
2. **Показывает тревожные уведомления** с растущей паникой
3. **"Взрывает" Omni** серией драматичных сообщений
4. **Признаётся что это шутка** 😎

## Как использовать?

### Запуск бомбы:
1. Открой Omni
2. Найди плагин **💣 Omni Bomb** в списке
3. Нажми кнопку **▶ Start**
4. БЕГИ! 🏃♂️💨

### Обезвредить бомбу:
1. Открой **Task Manager** (кнопка сетки ⊞ в хедере)
2. Найди **Omni Bomb** в списке
3. Нажми кнопку **✕ Kill**
4. Бомба обезврежена! ✅

## Технические детали

- **Тип**: `daemon` (фоновый процесс)
- **Длительность**: 10 секунд обратного отсчёта
- **Эффекты**: Toast уведомления с эмоджи
- **Безопасность**: 100% безопасно, не влияет на систему
